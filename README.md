# متجري الإلكتروني

متجر إلكتروني بسيط واحترافي لبيع المنتجات الرقمية والواقعية.

## الملفات الموجودة

- `index.html` → الصفحة الرئيسية
- `style.css` → التصميم
- `script.js` → الوظائف (السلة + واتساب)

## خطوات النشر على GitHub Pages

1. أنشئ حساب على GitHub (إذا ما عندكش)
2. أنشئ مستودع جديد (Repository) باسم مثلاً: `my-store`
3. ارفع الملفات الثلاثة (`index.html` + `style.css` + `script.js`)
4. اذهب إلى **Settings** → **Pages**
5. في Source اختر: **Deploy from a branch**
6. Branch: `main`   Folder: `/ (root)`
7. اضغط **Save**
8. بعد دقيقة إلى دقيقتين غادي يظهر رابط موقعك مثل:
   `https://اسم-المستخدم.github.io/my-store`

## تخصيص رقم الواتساب

افتح ملف `script.js` وبدل هذا السطر:

```js
const WHATSAPP_NUMBER = "2126XXXXXXXX";
```

حط رقمك ديالك (مثال مغربي: `212612345678`) **بدون** علامة `+` وبدون مسافات.

## تخصيص المنتجات

افتح ملف `script.js` وعدّل مصفوفة `products` حسب منتجاتك الحقيقية (الاسم، الثمن، الصورة، الوصف...).

## ملاحظات

- السلة تتحفظ في المتصفح (localStorage)
- عند الضغط على "إتمام الطلب عبر واتساب" كتفتح رسالة جاهزة في الواتساب
- التصميم متجاوب (يشتغل مزيان على الهاتف والكمبيوتر)
